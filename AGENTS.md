# AGENTS.md

## General Principles

- Write readable, simple, and maintainable code.
- Keep the code minimal and avoid unnecessary abstractions.
- Follow object-oriented programming principles where appropriate.
- Apply SOLID principles when they improve code structure and maintainability.
- Use clear and consistent naming for variables, functions, components, and types.

## Code Organization

- Extract repeated values into constants.
- Define explicit types and interfaces where appropriate.
- Group related logic into clear sections.
- Keep components and functions focused on a single responsibility.
- Reuse existing project structure and conventions.

## Complexity

- Avoid unnecessarily complex generics, nested lambdas, and deeply nested expressions.
- Prefer straightforward solutions over clever or overly abstract implementations.
- Do not introduce additional dependencies without a clear reason.

## Workflow

- Work step by step.
- Explain the purpose of each significant change.
- Keep changes small and easy to review.
- Do not modify unrelated files.
- Preserve existing functionality.
- Run the project checks after making changes and report any errors or warnings.
